# Dotfiles

Personal Fedora Linux workstation configuration.

## Contents

- Zsh + Starship
- tmux
- Neovim
- Alacritty
- Git configuration
- Local AI scripts
- Dolby Digital 5.1 PipeWire/ALSA setup
- systemd user services

## Installation

Clone the repository:

```bash
git clone <repo-url> ~/dotfiles
cd ~/dotfiles
./install.sh
```
